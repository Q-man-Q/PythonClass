# 🐍 Питон-Класс: Мультяшный интерактивный интерпретатор Python

> Обучающее веб-приложение для уроков информатики в школе и кружков программирования. Готово к публикации на **GitHub Pages**.

Веб-приложение наглядно демонстрирует, как устроен и работает интерпретатор Python: мультяшный персонаж (**Змейка Питончик Пип** или **Робот Байт**) физически перемещается по строчкам и отдельным элементам кода, подсвечивает вычисление операций, переносит значения в виртуальные коробочки оперативной памяти и объясняет каждое действие простым языком.

---

## 🚀 Как развернуть на GitHub Pages

Приложение является **100% клиентским статическим сайтом** (HTML5 + CSS3 + ES-модули JavaScript). Никаких сборщиков, серверов или баз данных не требуется!

1. Создайте репозиторий на GitHub и отправьте в него файлы:
   ```bash
   git add .
   git commit -m "Initial release of Python Cartoon Interpreter"
   git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
2. Откройте **Settings** вашего репозитория на GitHub ➔ перейдите во вкладку **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`
4. Нажмите **Save**. Через 1–2 минуты ваше приложение будет доступно по адресу:
   `https://ВАШ_АККАУНТ.github.io/ВАШ_РЕПОЗИТОРИЙ/`

## ✨ Возможности для уроков в школе

- 🐍 **Анимированные мультяшные персонажи**:
  - **Змейка Питончик (Пип)** в академической шапочке профессора с волшебной указкой.
  - **Робот Байт** с неоновым дисплеем эмоций и лазерным лучом.
- 🔍 **Детализация шагов**:
  - **Поэлементный режим**: персонаж пошагово проходит подвыражения (читает переменную ➔ выполняет операцию сложения `10 + 5 = 15` с всплывающим бэйджем ➔ переносит результат в коробочку переменной).
  - **Построчный режим**: быстрое перемещение от одной инструкции к другой.
- 🗄️ **Визуальная память ("Полочки с переменными")**:
  - Каждая переменная представлена в виде физической коробочки с типом (`int`, `str`, `list`, `bool`).
  - Анимация вспышки при записи нового значения и мягкая подсветка при чтении.
- 📚 **Стек вызовов функций (Call Stack)**:
  - Показывает переход внутрь функций (`def`) и возврат значений (`return`).
- 📺 **Ретро-монитор вывода**:
  - Терминал в реальном времени отображает результаты вызовов `print(...)`.
- ⌨️ **Интерактивный ввод `input()`**:
  - При выполнении команды `input()` всплывает диалоговое окно для ввода ответа с клавиатуры.
- 📚 **Каталог школьных уроков (Готовые пресеты)**:
  1. Переменные и арифметика
  2. Проверка условий (`if-elif-else`)
  3. Цикл `for` и `range` (сумма чисел)
  4. Цикл `while` (обратный отсчёт ракеты)
  5. Списки и метод `.append()`
  6. Собственные функции (`def` и `return`)
  7. Интерактивный диалог (`input`)
  8. Мини-игра "Угадай число"
- ✏️ **Свой код**:
  - Кнопка "Редактировать код" позволяет ученику или учителю вставить или написать абсолютно любую программу на Python.
- 📽️ **Режим для проектора и интерактивной доски**:
  - Увеличенный шрифт и повышенный контраст для демонстрации классу.
- 🔊 **Звуковые эффекты**:
  - Забавные звуки синтезатора Web Audio API (вычисления, запись в память, фанфары при успехе) с кнопкой быстрого отключения.
- 🔗 **Кнопка "Поделиться"**:
  - Кодирует введённый код в хэш URL (`#code=...`), позволяя учителю отправлять задания ученикам одной ссылкой.

## 🛠️ Локальный запуск и тестирование

Внутри каталога проекта:

```bash
# Запуск автоматических тестов парсера и трассировщика:
npm test

# Запуск локального сервера:
npm start
# или
python3 -m http.server 8000
```

Откройте в браузере: `http://localhost:8000`.

## 📁 Структура проекта

```text
├── index.html            # Главная страница приложения
├── package.json          # Конфигурация ES-модулей и тестов
├── README.md             # Инструкция и документация
├── src/
│   ├── app.js            # Координатор интерфейса, плеера и событий
│   ├── character.js      # SVG-персонажи (Пип и Байт), анимации и указка
│   ├── lexer.js          # Токенизатор Python с точными позициями токенов
│   ├── parser.js         # Построение AST (синтаксического дерева)
│   ├── tracer.js         # Виртуальная машина и пошаговый генератор трассировки
│   ├── memoryView.js     # Рендеринг коробочек памяти, стека и терминала
│   ├── presets.js        # Каталог готовых школьных примеров
│   └── sound.js          # Синтезатор звуков на Web Audio API
├── styles/
│   ├── main.css          # Основные стили, темы, режим проектора
│   ├── editor.css        # Подсветка кода, активные токены, бэйджи
│   ├── character.css     # Анимации мультяшных персонажей
│   └── memory.css        # Стилизация полочек памяти и ретро-экрана
└── tests/                # Набор тестов (node --test)
```
