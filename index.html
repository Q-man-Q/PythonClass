🎓 Как работает интерпретатор Python?

Python — это интерпретируемый язык программирования. Это означает, что специальная программа (интерпретатор) читает код сверху вниз и выполняет его команда за командой!

1. Токенизация (Разбор на слова)

Интерпретатор сначала разбивает текст на отдельные "кирпичики" — токены (числа, имена переменных, знаки сложения, ключевые слова if, for).

2. Построение дерева команд (AST)

Компьютер строит синтаксическое дерево, чтобы понять порядок действий (например, сначала умножение, потом сложение, сначала проверка условия, затем переход в ветку).

3. Память (Коробочки для переменных)

Когда вы пишете x = 5, интерпретатор выделяет в оперативной памяти коробочку с ярлычком x и кладёт внутрь значение 5. Когда в формуле встречается x, значение извлекается из коробки.

4. Экран вывода (print)

Команда print(...) передаёт данные на экран монитора (в консоль), чтобы результат работы увидел человек.

Горячие клавиши:

  • Пробел — Старт / Пауза воспроизведения
  • Стрелка вправо — Шаг вперёд
  • Стрелка влево — Шаг назад
